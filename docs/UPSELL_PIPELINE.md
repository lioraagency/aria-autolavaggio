# Upsell pipeline — ARIA Autolavaggio (LIORA)

**Positioning:** ARIA ships as **reservation funnel + staff cockpit**. Everything below is a **conversation ladder**—not a commitment to build without scoping.

## Stages

1. **Aware** — Client knows LIORA maintains the stack monthly.
2. **Interested** — Pain articulated (no-shows, manual reminders, reporting).
3. **Qualified** — Budget, owner, and timeline confirmed.
4. **Scoped** — Written add-on SOW or ticket batch.
5. **Delivered** — Shipped, measured, handed back to monthly cadence.

Track stage per opportunity in CRM or a client-private spreadsheet—not in git with PII.

## Suggested ARIA upsells

| Upsell | Value proposition |
|--------|-------------------|
| **SMS reminders** | Reduce no-shows; automated day-before / hour-before nudges. |
| **Google Calendar sync** | Owner/staff see washes on familiar calendar surfaces. |
| **Review request automation** | Post-service SMS/email asking for Google review with tracking. |
| **Loyalty system** | Visit counts, rewards, VIP lane—ties to Supabase customer record. |
| **No-show tracking** | Alerts + reporting; optional deposit later. |
| **AI receptionist** | After-hours SMS/voice triage—careful scoping for Québec language norms. |
| **Monthly analytics report** | PDF or email: volume, peak hours, service mix. |
| **Deposit / payment system** | Stripe or Moneris—legal and PCI scope required. |
| **Client reactivation campaigns** | Dormant customers, seasonal pushes, consent-based SMS blasts. |

## Qualification questions

- What is your **no-show rate** today, roughly?
- Who answers the phone **after hours**?
- Do you already ask for **Google reviews**—how?
- What tools do you use for **accounting** and **payroll** (integration interest)?
- Any **seasonal spikes** we should architect for (spring mud, winter salt)?
- **Consent:** can customers opt in to SMS marketing separately from transactional?

## Monthly review script (15–30 minutes)

1. “What broke or annoyed you this month?”  
2. “What manual step did you do more than five times?”  
3. Review **open incidents** from support log.  
4. Pick **one** upsell thread to advance or close.  
5. Confirm **next month’s** maintenance window if patches need scheduling.
